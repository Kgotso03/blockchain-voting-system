Global Multi-User Cloud Sync (Firebase)

Connect a free Firebase Realtime Database to allow everyone on Vercel or any device to cast votes into a single shared blockchain in real time!

How to get free Firebase in 2 mins:
1. Go to console.firebase.google.com → Click Add project.
2. In left menu: Build → Realtime Database → Create Database → Start in test mode.
3. Copy the database URL (e.g. https://xxx-default-rtdb.firebaseio.com) into the field above and click Save & Connect!
